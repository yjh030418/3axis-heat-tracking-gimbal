# 열원 추적 3축 카메라 짐벌 (진행 중)

> 카메라로 열원(불꽃)을 찾아 자동으로 따라가는 3축 서보 짐벌
> 제어를 직접 연습하기 위한 개인 프로젝트

## 목표

1. **1단계**: 3축 카메라 짐벌 구현 (자세 안정화, 표적 추적)
2. **2단계**: RGB 카메라만으로 불꽃·연기 탐지
3. **확장**: 소방 호스 조준, 4족 보행 로봇이나 드론 탑재

## 하드웨어

| 구성 요소 | 내용 |
| --- | --- |
| MCU | ESP32 |
| 액추에이터 | MG996R 서보 ×3 (Pan, Tilt, Roll) |
| 센서 | IMU (짐벌 아래 플랫폼), 카메라 |
| 기구 | Fusion 360으로 설계 예정 |

## 진행 상황

- [x] 부품 선정 (ESP32, MG996R)
- [ ] 짐벌 기구 모델링 및 출력
- [ ] 서보 3축 제어
- [ ] IMU 기반 자세 보정
- [ ] 카메라 표적 추적

## 참고

- Kim et al., *Global Motion-Aware Robust Visual Object Tracking for Electro Optical Targeting Systems*, Sensors 2020 — 짐벌이 움직일 때 추적기가 표적을 놓치는 문제를 다룬 논문으로, 이 프로젝트에 적용해 볼 계획
